# তাযকিয়াহ — ইসলামিক আত্মশুদ্ধি সংকলন

> **গুরুত্বপূর্ণ নোটিশ:** এই কন্টেন্টটি AI (কৃত্রিম বুদ্ধিমত্তা) দিয়ে প্রস্তুত ও সংকলিত। কঠোর সূত্র-মান নীতি মেনে শুধু সহীহ/হাসান হাদিস ও সহীহ সনদের আসার রাখা হয়েছে। তবে এটি কোনো আলেম বা মুহাদ্দিস কর্তৃক যাচাইকৃত নয়।

কুরআনের আয়াত, সহীহ হাদিস ও সাহাবিদের ঘটনা থেকে আত্মশুদ্ধির পূর্ণাঙ্গ সংকলন — অহংকার থেকে বাঁচা, নামাজের অর্থ জানা, দ্বিধা দূরীকরণ ও আল্লাহর রহমতের সন্ধান।
